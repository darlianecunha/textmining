Frequently asked questions

What is a co-occurrence network?

It is a network where each node represents a word and the links indicate that two words appear together in the same sentence. The more often they co-occur, the stronger the link. This is a classic analysis in bibliometrics and text mining.

How do I use the JSON in VOSviewer Online?

Download the generated JSON file, go to app.vosviewer.com, click "Open" in the top right, select "VOSviewer JSON file" and load the file.

Do scanned PDFs work?

Not directly. PDFs made up of images only need OCR first. The tool extracts text only from PDFs with a text layer (born-digital or with OCR already applied).

Which stopwords are removed?

Function words (the, and, of; de, que, não; el, los; il, della; le, des; der, und; het, van) are removed for seven languages: English, Portuguese, Spanish, Italian, French, German and Dutch. By default the app recognises the language of each document and applies the matching list, and a bilingual report gets both lists. To choose the languages yourself, untick the automatic option under Stopword languages. Generic academic terms (et al., doi, fig., table, journal) can also be removed with the option under Text cleaning, and you can add your own words to exclude.

How are compound terms detected?

With the option under Text cleaning switched on, two adjacent words become one term (shore power, climate change) when they occur together at least the number of times you set and in at least 15% of the occurrences of the rarer word. A second pass builds three-word terms the same way. Stopwords and punctuation break a compound, so "port of Rotterdam" is not detected automatically: add it to the thesaurus instead. The words inside a compound term are counted as the compound, not separately.

How does the thesaurus work?

Each line has a term and what to replace it with, for example "emissions, emission" or "carbon dioxide, co2". Terms can have several words on either side. An empty second column removes the term. Thesaurus rules are applied before stopwords, plurals and compound detection, and the format matches the thesaurus files used by VOSviewer.

The network produced no links — what now?

Try reducing the minimum frequency and minimum co-occurrence parameters. For short texts, values of 1 or 2 are usually enough. Increasing the maximum number of words also helps.
